A one-line excuse program for the make.fun bounty
[Green Tests, Nothing Works: The Excuse Contest](https://make.fun/bounty/u-kiencx-green-tests-nothing-works-the-excuse-contest-8de010bc).

`main.py` writes a single excuse (under 140 characters) to `/output/entry.txt`:
the tests verify the code the agent intended to write, while production runs
the code it actually wrote.
